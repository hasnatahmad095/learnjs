Array Methods in JavaScript

JavaScript provides various methods to manipulate arrays. Below are some important methods:

1. push() - Adds elements to the end of an array

const fruits = ["Apple", "Banana"];
fruits.push("Cherry");
console.log(fruits);
// Output: ["Apple", "Banana", "Cherry"]

2. pop() - Removes the last element from an array

fruits.pop();
console.log(fruits);
// Output: ["Apple", "Banana"]

3. shift() - Removes the first element from an array

fruits.shift();
console.log(fruits);
// Output: ["Banana"]

4. unshift() - Adds elements to the beginning of an array

fruits.unshift("Mango");
console.log(fruits);
// Output: ["Mango", "Banana"]

5. splice() - Adds or removes elements from a specific position

const numbers = [1, 2, 3, 4, 5];
numbers.splice(2, 1, 99);
console.log(numbers);
// Output: [1, 2, 99, 4, 5]

6. slice() - Extracts a portion of an array

const slicedNumbers = numbers.slice(1, 4);
console.log(slicedNumbers);
// Output: [2, 99, 4]
