JavaScript Type Conversion & Coercion

JavaScript allows conversion between different data types explicitly and implicitly.

1. Type Conversion (Explicit)

Manually converting one data type to another.

let num = "123";
let convertedNum = Number(num); // Converts string to number
console.log(typeof convertedNum); // Output: number
let bool = "";
let convertedBool = Boolean(bool); // Converts empty string to false
console.log(convertedBool); // Output: false
let str = 100;
let convertedStr = String(str); // Converts number to string
console.log(typeof convertedStr); // Output: string

2. Type Coercion (Implicit)

JavaScript automatically converts types when needed.

console.log("5" + 5); // Output: "55" (Number converted to String)
console.log("10" - 2); // Output: 8 (String converted to Number)
console.log(true + 1); // Output: 2 (Boolean converted to Number)
console.log(false + "test"); // Output: "falsetest" (Boolean converted to String)
