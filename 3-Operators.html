JavaScript Operators

JavaScript operators are used to perform operations on variables and values.

1. Arithmetic Operators

Used to perform mathematical calculations.

let a = 10, b = 5;
console.log(a + b); // Addition: 15
console.log(a - b); // Subtraction: 5
console.log(a * b); // Multiplication: 50
console.log(a / b); // Division: 2
console.log(a % b); // Modulus: 0
console.log(a ** b); // Exponentiation: 100000

2. Comparison Operators

Used to compare values and return a Boolean result.

console.log(a == b);  // Equal: false
console.log(a === b); // Strict equal: false
console.log(a != b);  // Not equal: true
console.log(a !== b); // Strict not equal: true
console.log(a > b);   // Greater than: true
console.log(a < b);   // Less than: false
console.log(a >= b);  // Greater than or equal: true
console.log(a <= b);  // Less than or equal: false

3. Logical Operators

Used to combine multiple conditions.

let x = true, y = false;
console.log(x && y); // AND: false
console.log(x || y); // OR: true
console.log(!x);     // NOT: false

4. Assignment Operators

Used to assign values to variables.

let num = 10;
num += 5; // num = num + 5 (15)
num -= 3; // num = num - 3 (12)
num *= 2; // num = num * 2 (24)
num /= 4; // num = num / 4 (6)
num %= 5; // num = num % 5 (1)
num **= 2; // num = num ** 2 (1)

5. Ternary Operator

Shorthand for if-else conditions.

let age = 18;
let status = (age >= 18) ? "Adult" : "Minor";
console.log(status); // Output: Adult
