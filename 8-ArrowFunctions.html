Arrow Functions in JavaScript

Arrow functions provide a shorter syntax for writing functions and automatically bind this to the surrounding scope.

1. Basic Arrow Function

const greet = () => "Hello, world!";
console.log(greet());

2. Arrow Function with Parameters

Passing parameters to an arrow function.

const add = (a, b) => a + b;
console.log(add(5, 3)); // Output: 8

3. Default Parameters

Providing default values for parameters.

const multiply = (a, b = 2) => a * b;
console.log(multiply(5)); // Output: 10
console.log(multiply(5, 3)); // Output: 15

4. Rest Parameters

Using the rest operator ...args to handle multiple arguments.

const sumAll = (...numbers) => numbers.reduce((acc, num) => acc + num, 0);
console.log(sumAll(1, 2, 3, 4, 5)); // Output: 15

5. Spread Operator

Expanding elements of an array or object.

const numbers = [1, 2, 3];
const newNumbers = [...numbers, 4, 5, 6];
console.log(newNumbers); // Output: [1, 2, 3, 4, 5, 6]

6. Arrow Function and this

Arrow functions do not have their own this context; they inherit from the enclosing scope.

const person = {
    name: "John",
    greet: function() {
        setTimeout(() => {
            console.log("Hello, " + this.name);
        }, 1000);
    }
};
person.greet(); // Output: Hello, John
