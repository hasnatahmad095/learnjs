
# JavaScript Concepts & Examples 🚀


This repository serves as a comprehensive guide to essential JavaScript concepts, including modern ES6+ features, functional programming, error handling, asynchronous JavaScript, and more. Each topic contains a brief explanation along with code examples to help developers understand and implement JavaScript effectively.




## 📌 Topics Covered


- ✅ Variables (var, let, const)
- ✅ Data Types (Primitive & Non-Primitive)
- ✅ Operators (Arithmetic, Logical, Comparison)
- ✅ Type Conversion & Coercion
- ✅ Conditional Statements (if-else, switch)
- ✅ JavaScript Loops & Loop Control (for, while, break, continue)
- ✅ Function Declaration vs Function Expression
- ✅ Arrow Functions & Parameters (Default, Rest, Spread)
- ✅ Arrays & Array Methods (push, pop, shift, unshift, splice, slice)
- ✅ Array Iteration Methods (map, filter, reduce, forEach, find, some, every)
- ✅ Destructuring Arrays & Objects
- ✅ JavaScript Objects & Methods (Object.keys(), Object.values(), Object.entries())
- ✅ Template Literals (String Interpolation)
- ✅ Modern JavaScript (ES6+) (let, const, arrow functions, modules)
- ✅ DOM Manipulation (Selecting, Modifying, Adding, Removing Elements)
- ✅ Event Handling in JavaScript (addEventListener, Event Delegation)
- ✅ Callbacks, Promises, and Async/Await
- ✅ Fetch API (fetch(), json(), error handling)
- ✅ setTimeout & setInterval (Timers in JavaScript)
- ✅ Error Handling in JavaScript (try...catch...finally, throw, Custom Errors)
- ✅ localStorage & sessionStorage (setItem(), getItem())
- ✅ JSON.stringify() & JSON.parse() (Working with JSON)
- ✅ Functional Programming (Higher-Order Functions, Closures, Currying, Memoization)
- ✅ Regular Expressions (RegEx) (match(), replace(), test(), Patterns)
