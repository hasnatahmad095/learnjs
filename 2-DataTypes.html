JavaScript Data Types

JavaScript has two types of data types:

  • Primitive Data Types
  • Non-Primitive (Reference) Data Types

Primitive Data Types

JavaScript has 7 primitive data types:

  • String
  • Number
  • Boolean
  • Null
  • Undefined
  • Symbol
  • BigInt

1. String

A sequence of characters enclosed in quotes.

let name = "John Doe";
console.log(name); // Output: John Doe

2. Number

Can be an integer or a floating-point value.

let age = 25;
let price = 99.99;
console.log(age, price); // Output: 25 99.99

3. Boolean

Represents true or false values.

let isStudent = true;
console.log(isStudent); // Output: true

4. Null

Represents an intentional empty or unknown value.

let emptyValue = null;
console.log(emptyValue); // Output: null

5. Undefined

A variable that has been declared but not assigned a value.

let notAssigned;
console.log(notAssigned); // Output: undefined

6. Symbol

Represents a unique identifier.

let uniqueID = Symbol("id");
console.log(uniqueID); // Output: Symbol(id)

7. BigInt

Used for very large numbers.

let bigNumber = BigInt(9007199254740991);
console.log(bigNumber); // Output: 9007199254740991n

Non-Primitive (Reference) Data Types

These data types are objects and stored by reference:

  • Object
  • Array

1. Object

A collection of key-value pairs.

let person = {
  name: "John",
  age: 30
};
console.log(person.name); // Output: John

2. Array

An ordered collection of values.

let colors = ["Red", "Green", "Blue"];
console.log(colors[0]); // Output: Red
