Regular Expressions in JavaScript

What are Regular Expressions?

Regular Expressions (RegEx) are patterns used to match character combinations in strings. They are commonly used for validation, searching, and text manipulation.

Using match() to Find Matches

The match() method searches for matches in a string based on a regular expression.

Using replace() to Modify Strings

The replace() method replaces text that matches a pattern.

Using test() to Check for Matches

The test() method returns true or false based on whether the pattern is found.

Common RegEx Patterns

  • \d - Matches any digit (0-9).
  • \w - Matches any word character (letters, numbers, underscore).
  • \s - Matches whitespace (spaces, tabs).
  • ^ - Matches the beginning of a string.
  • $ - Matches the end of a string.
  • + - Matches one or more occurrences.
  • ? - Matches zero or one occurrence.
  • * - Matches zero or more occurrences.
  • {n} - Matches exactly n occurrences.
