Array Iteration Methods in JavaScript

JavaScript provides several methods to iterate over arrays efficiently. Below are some key methods:

1. map() - Creates a new array by applying a function to each element

const numbers = [1, 2, 3, 4];
const doubled = numbers.map(num => num * 2);
console.log(doubled);
// Output: [2, 4, 6, 8]

2. filter() - Creates a new array with elements that pass a test

const evenNumbers = numbers.filter(num => num % 2 === 0);
console.log(evenNumbers);
// Output: [2, 4]

3. reduce() - Reduces an array to a single value

const sum = numbers.reduce((acc, num) => acc + num, 0);
console.log(sum);
// Output: 10

4. forEach() - Executes a function for each element

numbers.forEach(num => console.log(num * 2));
// Output: 2, 4, 6, 8 (each logged separately)

5. find() - Returns the first element that passes a test

const found = numbers.find(num => num > 2);
console.log(found);
// Output: 3

6. some() - Checks if at least one element passes a test

const hasEven = numbers.some(num => num % 2 === 0);
console.log(hasEven);
// Output: true

7. every() - Checks if all elements pass a test

const allPositive = numbers.every(num => num > 0);
console.log(allPositive);
// Output: true
