Callbacks

A callback is a function passed as an argument to another function. It is executed after the completion of the function it was passed to.

Promises

A Promise is an object representing the eventual completion or failure of an asynchronous operation. It can be in one of three states: pending, resolved, or rejected.

Async/Await

Async/Await is a modern way to handle asynchronous operations. The 'async' keyword makes a function return a Promise, and 'await' pauses execution until the Promise resolves.
