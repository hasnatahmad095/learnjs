Functional Programming in JavaScript

1. Higher-Order Functions

A function that takes another function as an argument or returns a function.

2. Pure Functions

A function that does not modify external states and returns the same output for the same input.

3. Closures

A function that remembers the scope in which it was created.

4. Recursion

A function that calls itself until a base condition is met.

5. Currying

Transforming a function with multiple arguments into a sequence of functions.

6. Memoization

Optimization technique where function results are stored to avoid redundant calculations.
