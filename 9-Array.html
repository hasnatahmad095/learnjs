Creating Arrays in JavaScript

Arrays in JavaScript can be created using square brackets [] or the Array() constructor.

1. Creating an Array Using Square Brackets

const fruits = ["Apple", "Banana", "Cherry"];
console.log(fruits);
// Output: ["Apple", "Banana", "Cherry"]

2. Creating an Array Using the Array() Constructor

const numbers = new Array(1, 2, 3, 4, 5);
console.log(numbers);
// Output: [1, 2, 3, 4, 5]

3. Creating an Empty Array

const emptyArray = [];
console.log(emptyArray);
// Output: []

4. Creating an Array with a Specified Length

const sizedArray = new Array(5);
console.log(sizedArray);
// Output: [empty × 5] (an array with 5 empty slots)
